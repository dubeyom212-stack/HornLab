# Trying HornLab with friends

## What I heard

I had five French horn friends try the live PythonAnywhere app. They liked it, but entering their pieces and repertoire took too long. I shared that feedback on November 2, 2026.

These are my notes from what they told me, not a survey or a count of regular users.

## What I changed

The piece name is now the only thing you need to enter up front. Deadline, priority, category, and confidence are optional details you can come back to.

There's also a way to paste up to 50 piece names at once. It previews the names, ignores blank lines, and skips repeated names or pieces already in that profile, including archived ones.

Finally, I added Save & practice and a Practice button beside each active piece. Those use an existing passage goal or set up a basic whole-piece goal. This means you can start without filling out another form.

The friends pointed out the slow setup. These particular changes were my response to that feedback.

## What I want to check next

Have those same friends try the updated version:

- Can they add a piece and start practice without help?
- Does pasting a list work with the repertoire they actually have?
- Is it clear how to change the default tempo or add a specific measure range?
- What still feels slow or confusing?
- Do they use it again after the first try?

If I compare setup times, I need to use the same task and record the device too. For now, I haven't measured that or had the friends retest this update.

I also want to check recording and playback on their phones. I won't put anyone's private practice notes, names, or recordings in this repo.
